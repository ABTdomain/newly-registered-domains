**DomainKits.com** makes analyzing NRDs easier.

## What makes DomainKits different

A typical NRD list is a file that arrives once a day. DomainKits runs NRDs as a live 60-day stream:

- **Every 15 minutes, not once a day.** Our NRD database updates in the background and syncs into your workflow every 15 minutes.
- **1,400+ TLDs, ccTLDs included.** gTLDs plus major ccTLDs, such as `.com`, `.xyz`, `.ai`, `.io`, `.br` and `.in`.
- **60 days of continuous monitoring.** Rich data detail and a longer observation period.
- **No registrant PII.** Focused on technical domain data, GDPR-friendly.
- **Rich access options.** Five different ways to access NRDs, built for a range of workflows.

### [CLI](https://github.com/ABTdomain/domainkits-cli)

Uses the DomainKits API from the command line: `dk` is one binary with no dependencies, takes `key=value` parameters, prints the API response as returned, and returns exit codes that AI agents and scripts can branch on (`0` success, `1` API error, `2` usage or network error).

```bash
export DOMAINKITS_API_KEY=dk_...
dk download tld=com type=domains_only      # pull the free daily NRD list
dk search nrds query=ai tld=com limit=20   # query the 15-minute NRD stream
```

- **Install**: [ABTdomain/domainkits-cli](https://github.com/ABTdomain/domainkits-cli), or `go install github.com/ABTdomain/domainkits-cli/cmd/dk@latest`
- **Orchestrate your own AI workflow**: pick the commands you need and chain them together
